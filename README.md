# Dugina trka

2D igrica za Leonu: jednorog i Leona trče kroz 7 svjetova (28 razina), skupljaju prstenove i vraćaju boje sivoj karti.

- Igraj: https://markofrankovic-afk.github.io/duginatrka/
- `index.html` je igra, `a/` su slike i glazba.
- `src/` je izvorni kod: `cat src/head.html src/game.js src/tail.html > index.html`.
- `src/glazba-gen.py` generira glazbu (vlastite skladbe), `src/slike-pripremi.py` priprema slojeve pozadina.

Pozadine: Free Game Assets / CraftPix (Free Parallax 2D Backgrounds, Free Fairy-Tale 2D Backgrounds), prema njihovoj licenci.
